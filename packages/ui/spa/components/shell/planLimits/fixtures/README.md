# Plan limit fixtures

These files are generated by valbuild/home's
`content/src/billing/tierStates.test.ts` from the real server code, and copied
here unchanged. They are not hand-written: to update them, regenerate them in
valbuild/home (`UPDATE_TIER_STATES=1`) and copy the new files over.

- `access-*.json` — the `limits` object of `GET /orgs/:org/projects/:project/access`
  for each plan state.
- `refused-*.json` — the 403 body of a save, publish or upload Val Build
  refused for the plan.

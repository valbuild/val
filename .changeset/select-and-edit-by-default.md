**Select & edit is now what Select starts in.** Turning Select on in the Studio's preview and clicking a text puts the caret in it, on the page; anything that is not a text still opens in the column, as before. The menu beside Select still has plain **Select**, which opens every field in the column, and the mode you choose is remembered per browser.

If you had chosen Select & edit already, nothing changes. If you had not chosen, or had gone back to plain Select, Select is now Select & edit until you pick plain Select from the menu again.

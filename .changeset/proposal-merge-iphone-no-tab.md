On an iPhone or in Safari, **Publish** in a proposal opens a builder tab only when the merge has something to build. A proposal of content alone, or one whose code is already built, is now published from the page itself. A merge that turns out to need a build asks for the tab with one more tap, and that tap now publishes the proposal rather than the site's own pending changes.

The Sketchpad now uses the Studio's preview instead of a preview of its own. Pressing a page in the Sketchpad shows it in the preview beside it, with the same address bar, device widths, zoom, Select and quick preview as everywhere else, and closing the Sketchpad leaves the preview where it was rather than loading the page again. Review's "Compare with the site" shows both sides in the same preview too. Opening a Sketchpad opens the Sketchpad alone; the assistant opens when you send it something.

**Code mode on the site.** On a project Val Build hosts, `</>` on the site no longer asks you to choose or start a proposal: one press turns code mode on for the site, and the assistant can change the site's code there. Everything waiting to be published goes with it, so a schema change and the content it affects stay together, and the site changes when you publish, after a build and a check that the site still renders.

It is on by default. A project's owners and developers can turn it off in Val Build (the project's page, Publishing, "Code mode on the site"). With it off, `</>` lists proposals as before.

The assistant's "Turn on code mode?" card on the site does the same.

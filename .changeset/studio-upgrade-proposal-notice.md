In an upgrade proposal, the Studio now says what the proposal upgrades — for example "This proposal upgrades Val 0.149.4 → 0.149.7", or that it fixes security issues — that it holds no content changes, and that publishing it updates the site. The notice has a **Publish to update your site** button, the packages it changes (majors marked), and a link to the upgrade's checks in Val Build.

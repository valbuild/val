Studio canvas: when the page in the canvas is not in preview mode, or does not answer, the message now sits at the bottom of the canvas, directly above the select button, instead of over the top of the page. The select button is always shown in that state, outlined, and pressing it turns preview mode on and goes straight into select mode. It replaces the "Turn on preview mode" button that used to be on the message.

# Independent publish (removed)

Patch groups -- a per-author set of patch ids that a publish shipped, so two
editors could publish independently -- were removed in October 2026. The site's
Publish ships every pending change, and work kept apart lives in a proposal.

See [`docs/plans/remove-patch-groups.md`](../plans/remove-patch-groups.md) for
why, and what replaced it. The design that was here is in git history.
